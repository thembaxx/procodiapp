# Choose your view

All three directions share the same real data, store search, category filters, terms, bookmarks, copy behaviour and refresh service.

## 1. Wallet — recommended

Closest to the Apple Wallet and retailer-card references. A quiet dark canvas, soft mint typography, overlapping brand-colour cards and a single expanded store. The active store changes the ambient glow. This is the default view.

![Wallet mobile](previews/wallet-phone.png)

## 2. Rewards

Inspired by the PayPal rewards reference. A bold blue dashboard, bright surfaces, playful Bricolage typography and individually visible offers. The desktop uses a responsive card grid; the phone uses a single column.

![Rewards mobile](previews/rewards-phone.png)

[Full page](previews/rewards-mobile.png) · App route: `/?design=rewards`

## 3. Orbit

An editorial alternative with lavender accents, large serif store names and horizontally snapped cards. Swipe to explore stores; all promotion details remain on the card.
